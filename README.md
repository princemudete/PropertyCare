# Maintenance Frontend

A React frontend for the Django maintenance request API.

## Setup

1. Open a terminal in `software-dev-specialisation/frontend`
2. Run `npm install`
3. Run `npm run dev`

The app uses `http://127.0.0.1:8000/api` for backend requests and preserves cookies with `credentials: 'include'`.

## Available pages

- Login
- Current user info
- Request list
- Create new maintenance request
- Update request status
